📧 Visualiseur d'Emails de Développement

Consultez tous les emails envoyés par votre application Laravel

✅ Mode actuel : Vos emails sont enregistrés dans les fichiers de logs Laravel (MAIL_MAILER=log)

🔍 Comment voir les emails actuellement :

  1. Ouvrir le fichier : storage/logs/laravel.log
  2. Chercher les emails récents (ils contiennent le HTML complet)
  3. Copier le lien contenu dans l'email

📊 Options de visualisation

ACTIF

1️⃣ Logs Laravel

Les emails sont enregistrés dans les fichiers logs. Simple mais pas très visuel.

Commande PowerShell :

Get-Content storage\logs\laravel.log -Tail 500

Ou via VS Code :

Ouvrir directement storage/logs/laravel.log

RECOMMANDÉ

2️⃣ Mailtrap.io

Service gratuit qui capture tous vos emails avec une interface web magnifique !

Configuration :

  1. Créer un compte sur mailtrap.io
  2. Créer une "inbox"
  3. Copier les identifiants SMTP
  4. Modifier votre .env :
MAIL_MAILER=smtp MAIL_HOST=sandbox.smtp.mailtrap.io MAIL_PORT=2525 MAIL_USERNAME=votre_username MAIL_PASSWORD=votre_password MAIL_ENCRYPTION=tls
Créer un compte gratuit

3️⃣ MailHog

Serveur SMTP local avec interface web. Idéal pour le développement sans internet.

Installation :

  1. Télécharger depuis GitHub
  2. Lancer mailhog.exe
  3. Ouvrir http://localhost:8025
MAIL_MAILER=smtp MAIL_HOST=localhost MAIL_PORT=1025 MAIL_USERNAME=null MAIL_PASSWORD=null MAIL_ENCRYPTION=null
AVANCÉ

4️⃣ Laravel Log Viewer

Package pour visualiser les logs directement dans votre navigateur.

Installation :

composer require rap2hpoutre/laravel-log-viewer

Puis accéder à : http://127.0.0.1:8000/logs

⚠️ Note importante :

J'ai détecté une erreur dans vos logs : "Duplicate entry 'mainelmudib8@gmail.com'"

L'utilisateur existe déjà dans la table users. Il faut le supprimer d'abord avant de réapprouver la pré-inscription.

Solution rapide :

php artisan tinker User::where('email', 'mainelmudib8@gmail.com')->delete(); exit
