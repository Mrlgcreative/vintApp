Guide Rapide
Étapes de Test
  1. Sélectionnez un opérateur
  2. Choisissez un statut (success/failed)
  3. Ajustez les valeurs si nécessaire
  4. Cliquez sur "Envoyer le Callback"
  5. Vérifiez la réponse
Codes de Statut
  • Success: Transaction réussie
  • Failed: Transaction échouée
  • Pending: En attente
  • Cancelled: Annulée
